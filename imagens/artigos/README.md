# Article Images

These photorealistic botanical images were generated specifically for this project. They were not copied from stock libraries or third-party websites. The `-cover.webp`, `-step-1.webp`, and `-step-2.webp` files are alternate crops of each article’s topic-specific image.

These are AI-generated images, not documentary photographs of actual plants or pests. Review any image used for botanical identification before treating it as a factual reference.
